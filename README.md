# Jiawei Chen · Academic Homepage

Personal academic homepage for Jiawei Chen (陈佳伟), Galbot and EPIC Lab.

Website: https://pku-cs-cjw.top/

This static site is served through GitHub Pages. Edit `index.html` to update the biography, publications, and links; edit `styles.css` for the appearance. Images are in `assets/`. No build step is required.

To preview locally, run `python3 -m http.server 8765 --bind 127.0.0.1` and open http://127.0.0.1:8765/ .

The earlier blog is preserved in the Git history and the `legacy-blog-before-academic-20261009` branch.
